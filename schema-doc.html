Database Architecture

โครงสร้างฐานข้อมูล PostgreSQL / pgAdmin 4

เอกสารคู่มือ DDL Schema ที่อยู่ในไฟล์ schema.sql พร้อมสำหรับนำไป Exec ใน Query Tool

1 universities

เก็บรายชื่อมหาวิทยาลัย (MSU, KKU, SUT, UBU) และพิกัดศูนย์กลาง

2 dorms

เก็บข้อมูลหลักหอพัก, ค่าเช่า, อัตราค่าน้ำไฟ, สิ่งอำนวยความสะดวก และ URL Google Maps

3 dorm_ratings

คะแนนประเมิน 6 มิติ (ความเงียบสงบ, น้ำประปา, Wi-Fi, ความปลอดภัย, เจ้าของหอ, ความสะอาด)

4 ai_review_summaries

เก็บข้อมูลข้อดี-ข้อควรทราบที่สรุปโดย AI แบบ JSONB format

5 dorm_photos

เก็บบันทึกรูปภาพโดยจำแนกประเภท ENUM ('STUDENT', 'LANDLORD')

6 dorm_qa

เก็บกระทู้ถาม-ตอบระหว่างผู้สนใจและศิษย์เก่า/ผู้พักปัจจุบัน

📄 schema.sql (PostgreSQL DDL) PostgreSQL 14+ / pgAdmin 4 
-- CREATE TABLES EXAMPLE
CREATE TABLE dorms (
    id SERIAL PRIMARY KEY,
    university_id INT REFERENCES universities(id) ON DELETE CASCADE,
    name_th VARCHAR(100) NOT NULL,
    address TEXT,
    distance_km NUMERIC(4, 2) NOT NULL,
    walking_min INT NOT NULL,
    price_monthly INT NOT NULL,
    water_rate NUMERIC(5, 2) NOT NULL,
    electric_rate NUMERIC(5, 2) NOT NULL,
    google_map_embed_url TEXT,
    google_map_url TEXT,
    overall_rating NUMERIC(3, 2) DEFAULT 0.0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE dorm_photos (
    id SERIAL PRIMARY KEY,
    dorm_id INT REFERENCES dorms(id) ON DELETE CASCADE,
    photo_url TEXT NOT NULL,
    photo_source VARCHAR(20) DEFAULT 'STUDENT',
    caption VARCHAR(150),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
